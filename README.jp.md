## 戦場

1942年6月5日未明、ミッドウェー海戦は終結した。日本艦隊は撤退している。

しかし北方海域で、アメリカ海軍の特混編隊が迎撃態勢に入っていた。戦艦アイオワ（BB-61）とサウスダコタ（BB-57）は、第一戦隊の退路を塞ぐ命令を受けている。

アイオワはアメリカ海軍最速の戦艦——33ノット、16インチ50口径Mark 7砲9門、SGレーダー搭載。サウスダコタの艦橋にはマッカーサーが座っている。彼はフィリピン戦役を指揮した陸軍大将だが、海戦の専門家ではない。彼の電報は時に示唆に富むが、時に戦局と無関係である。

対するは日本海軍の九隻：長門、陸奥、金剛、榛名——四隻の戦艦。雪風、陽炎、磯風、不知火、黒潮——五隻の陽炎型駆逐艦。全艦に**九三式酸素魚雷**を搭載——航跡は淡く、射程22-40km、490kg弾頭。

## 兵装システム

### 主砲/副砲分離
アイオワは片舷10門ずつ計20門の5インチ38口径副砲を装備。副砲は戦闘中に自動射撃し、駆逐艦を優先目標とする。30HPを超える命中弾は駆逐艦の主砲1門を一時的に使用不能にする——つまり魚雷発射管が減る。

### 弾薬種別
- **AP徹甲弾**（標準装備）：主力艦に有効な貫通力＋内部爆発効果。駆逐艦に対しては過貫通となり15-40HPの損傷
- **HC高爆弾**：駆逐艦の上部構造を破壊し、火災を発生させる（80-140HP+）。主力艦には跳弾される可能性が高い

戦闘前に弾薬種を選択できる。選択を誤れば斉射の機会を浪費する。

### 至近弾
16インチ砲弾が駆逐艦の4km以内に落下し、かつ全弾逸脱した場合、約20%の確率で至近弾衝撃波が発生する：20-80HPの構造損傷、22%の確率で軽度浸水。日本側指揮官は至近弾を報告しないが、航速の低下で観測可能。

### 雪風
雪風（陽炎型第8番艦、呉海軍工廠、1940年竣工）は独自の確率判定機構を持つ。戦闘開始前に独立判定が行われる：
- 天命加護（20%）：回避率+35%、致命的被弾耐性+60%、弾薬庫保護+70%
- 身邊の厄運（15%）：同編隊艦船の損傷が増加
- 帰郷意志（10%）：船体回復、速力維持、乗員回復
- 幸運の呪い（20%）：回避率+20%、一撃必殺無効
- 幽霊艦隊（8%）：特定確率で欺瞞目標出現

約61%の確率で1つ以上の効果が発動する。

## 戦術的助言

1. SGレーダーは夜戦における最大の優位——32km探知可能に対し日本軍は10-12kmの目視限界。レーダーを保護し、優先的に交戦距離を確保せよ。
2. 火力を一隻に集中せよ。日本艦隊には内部矛盾が存在し、旗艦の喪失はそれを増幅する。
3. アイオワの33ノットは交戦の主導権を提供する——接近と離脱のタイミングは自ら選択できる。
4. 副砲は8km以内で駆逐艦に有効。早期に副砲射程に入ることで日本の魚雷攻撃能力を削減できる。
5. 九三式魚雷はソナーやレーダーで探知不能。目視で航跡を発見した時点で、回避の時間的余裕はほとんどない。
